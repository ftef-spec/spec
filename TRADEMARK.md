# Name and conformance claims

"FTEF" and "Federated Trust Evidence Framework" name this specification. The names are not registered trademarks.

- You may use the names to refer to the specification, and to describe an implementation that implements it.
- You may say an implementation "conforms to FTEF 0.1" only if it meets every MUST of the conformance classes it claims (section 7), names those classes and the profiles it implements, and passes `tools/check.py` for the documents it produces.
- A modified version of the specification must not be called FTEF, and must not claim conformance to FTEF, without a clear statement of what was changed.
- The mark (`site/` and the organisation profile) may be used to point to this project, unmodified.
